# tobi-stack

Rules for working in this repo. The global rules every agent loads live in `GLOBAL.md`.

## Git workflow

- Commits go to `main` directly. No branches.
- Push only when asked.
- No PRs. Commits on `main` are the record.
- "Review this" means show the skill word for word, critique it, and let the user pick the fixes.
- Run `scripts/check.sh` before every commit.
